
# Court Case and Legal Evidence Management System

A full-stack database management application designed to manage court cases, legal parties, lawyers, judges, hearings, evidence, witnesses, documents, and judgments.

## Project Overview

This system aims to digitize and streamline the legal case management process through a centralized database and interactive web application.

## Technology Stack

- Database: MySQL 8
- Backend: Python, Flask
- Frontend: React.js
- Styling: Tailwind CSS
- Version Control: Git and GitHub

## Core Modules

- Court and Case Management
- Judge and Lawyer Management
- Party and Witness Management
- Hearing Scheduling
- Evidence Management
- Chain of Custody Tracking
- Document Management
- Judgment and Deadline Management
